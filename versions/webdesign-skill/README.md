# Sara Ankava · גרסת "בדיקת הסקיל" (webdesign-skill)

נבנתה מהפרומפט המלא, לפי: `מבנה דף הבית.png`, `אפיון האתר/`, `סגנון עיצובי.jpg`, `צבעוניות.jpg`, `לוגו/`, `סופי/` (אובייקט ה-a) ופונט Sara Ankava v1.2.
תיקייה עצמאית: לא נגעתי ב-v1–v6 ובקבצי השורש של האתר.

## איך מריצים
`node server.js` בתיקייה הזו, ואז http://localhost:5192 (או `sara-skill` ב-launch.json של פרויקט הסקיל).
העמודים נבנים מתבנית: `node tools/build.js` (העריכה בקבצים `tools/lib.js` ו-`tools/build.js`, לא ב-HTML).

## מה בפנים
index (7 אזורים לפי האפיון) · projects · project-tefillin · project-system · legal · 404.
חוק 60-30-10: פחם `#0E1110` · בהיר `#F3F3EE` · ליים `#C6FF34` (ליים מקובץ הצבעוניות). הזוהר רק באובייקט ההירו. כל האיורים בזכוכית בלי זוהר.

## החלטות שצריך לאשר
1. **פחם ובהיר:** קובץ הצבעוניות מגדיר שחור `#000000` וליים `#C6FF34` בלבד. "פחם" נשאר `#0E1110` וה"בהיר" `#F3F3EE`, כמו בגרסאות הקודמות. אם צריך ערכים אחרים, משנים ב-`:root` ב-`assets/css/site.css`.
2. **טקסט רץ ב-Rubik** (Google Fonts), הכותרות בפונט המותג.
3. הטופס **לא שולח לשום מקום** עד שמדביקים כתובת ב-`ENDPOINT` בראש `assets/js/site.js`. עד אז הפרטים עוברים לוואטסאפ בלחיצה אחת.
4. `robots: noindex` בכל העמודים, עד שמחליטים לעלות.
