# Sara Ankava — אתר פורטפוליו

## איך פותחים
```
node server.js
```
ואז http://localhost:5173 . (אפשר גם להעלות את כל התיקייה כמו שהיא לכל אחסון סטטי: Netlify, Vercel, GitHub Pages.)

## מה להחליף לפני שהאתר עולה
1. **מספר וואטסאפ** (כבר מוגדר: 053-3175560): בקובץ `assets/js/main.js`, בשורה `WA_NUMBER`.
2. **התמונה שלך**: שמרי תמונה בשם `sara.jpg` בתיקייה `assets/img` (יחס 4:5, עד 300KB). היא תופיע אוטומטית באזור "קצת עליי".
3. **צילומי מסך של הפרויקטים**: המוקאפים בנויים בקוד כהמחשה. כשיש צילומים אמיתיים, מחליפים את תוכן `.mock__win` בתמונה.
4. **טקסטים בעמוד הפרויקט** (`project-tefillin.html`): "מה היה לפני" ו"מה ראיתי בנתונים" כתובים כטיוטה. לעדכן לנתונים האמיתיים.
5. **אזור "מה יצא"** בעמוד הפרויקט ואזור **המלצות** בדף הבית מסומנים בהערה בקוד. נכנסים רק כשיש מספר אמיתי / 3–4 המלצות אמיתיות.
6. **אינסטגרם**: לא הוסף לפוטר כי אין כתובת. מוסיפים `<li>` בעמודת "קשר".

## מבנה
- `index.html` דף הבית (8 אזורים לפי האפיון) · `projects.html` · `project-tefillin.html` · `legal.html` (נגישות ופרטיות) · `404.html`
- `assets/css/style.css` כל העיצוב: 3 צבעים מהלוגו, 5 גדלי טקסט, 4 ריווחים
- `assets/brand/` ה-a והנקודה מהלוגו (SVG), favicon
- `assets/fonts/` פונט Sara Ankava (WOFF2). טקסט רץ ב-Rubik מ-Google Fonts.

## אחרי עדכון קבצים
ה-CSS וה-JS נטענים עם `?v=9` בסוף הכתובת. כשמשנים אותם, מעלים את המספר (v=10) בכל עמוד, כדי שדפדפנים לא יציגו גרסה ישנה.

## עיצוב מחדש (אוקטובר 2026)
**גוונים** (כל גוון זז מעט מהקודם, הכול עובר AA): נייבי `#150029` (היה `#1c0d27`: הו -3°, רוויה -8%, בהירות +1%), נייבי-2 `#220A3C`, דיו `#0D0019`, נייר `#F5F4F1`, ליים `#CFF839`, סגול `#723BF8`. הטוקנים בראש `assets/css/style.css`.
**לוגו:** לבן על כהה, כהה על בהיר, והריבוע ירוק או סגול. נבנה מהפונט (וקטורי, לא PNG עם רקע) ב-class `.logo`; לגרסה על בהיר: `.logo--dark`, לריבוע סגול: `.logo--violet`.
**תפריט:** קישורים גלויים בדסקטופ + כפתור MENU למסך מלא. הסטטוס החי בתפריט תלוי בשעות הפעילות שב-`HOURS` בקובץ `assets/js/main.js` (א׳-ה׳ 9:00-18:00, שישי ושבת סגור. אושר).
**תמונה באודות:** `assets/img/sara.jpg` (ריבועית, עד 300KB). עד אז מוצגת צורה. הטקסט המסתובב סביבה: משפט הבידול, בקובץ `index.html` (מוגדר הפוך באותיות בכוונה, כדי שייקרא נכון על העיגול).
**מוקאפים:** נוצרים בקוד (`mocks.js` בסביבת העבודה). כשיהיו צילומי מסך אמיתיים, מחליפים את תוכן `.mk__win` בתמונה.

## פונט
Sara Ankava גרסה 1.2 (Light 300 / Medium 500 / Bold 700) ב-`assets/fonts/*-v1.2.woff2` עם `.woff` כגיבוי. הריווח שאושר נשמר: `letter-spacing:0` ו-`word-spacing:0` בכל מקום שבו הפונט בשימוש. כשמחליפים גרסה: מעדכנים את שמות הקבצים ב-`@font-face` ובשורת ה-preload של כל עמוד, ומעלים את `?v=`.

## Redesign של הירו והדר (אוקטובר 2026, סבב ב׳)
- **לוגו:** `assets/brand/logo-light.png` (לבן) ו-`logo-dark.png` (נייבי), חתוכים ושקופים, נגזרו מקובץ הלוגו המקורי בתיקיית "לוגו". הריבוע הוא אלמנט נפרד (`.logo__sq`) כדי שיוכל לזוז ב-hover. על בהיר: `.logo--on-light`.
- **הדר:** לוגו מימין, קפסולה צפה (glass) במרכז עם אינדיקטור פעיל ופס התקדמות, כפתור CTA משמאל. מתחת ל-960px: כפתור שפותח מסך מלא.
- **הירו:** כותרת, שורת בידול, כפתור אחד, וויז'ואל קנבס יחיד (`[data-funnel]` ב-`main.js`): משפך נקודות עם "דליפה" שנסגרת בהעברת עכבר או בגלילה. המספר מחושב מהסימולציה והוא **המחשה** (כתוב כך בממשק).
- **קנה מידה:** h1 `clamp(40px,5vw,68px)`, כותרות מקטע עד 56px, גוף 17-18px, container 1200px, ריווח מקטעים עד 140px.
- הוסרו: פרילואדר, זום/pin בהירו, מסך המניפסט הליים, וורדמרק הפוטר המוקלד (הוחלף בלוגו).
